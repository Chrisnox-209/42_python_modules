# 📚 Piscine Python — De la Syntaxe Garden à la Magie Fonctionnelle (42 Project)

## 🎯 Objectif du projet

Ce projet consiste à maîtriser le langage Python à travers 11 modules thématiques.
Le but : comprendre en profondeur la manipulation de données, l'ingénierie logicielle, la programmation orientée objet et les paradigmes fonctionnels.
Chaque module explore un univers spécifique (Smart Agriculture, Digital Matrix, Cosmic Data) pour appliquer des concepts techniques à des cas concrets.

---

## 🧩 Modules et Progression

Le cursus est structuré autour de la montée en puissance des compétences :

### 🌱 Fondations & Données (00 - 03)
- **Module 00 : Growing Code** — Syntaxe de base, variables et fonctions à travers l'analyse d'un jardin.
- **Module 01 : Code Cultivation** — Introduction à l'Orienté Objet et aux simulateurs de croissance.
- **Module 02 : Garden Guardian** — Data Engineering, gestion d'erreurs et pipelines de validation.
- **Module 03 : Data Quest** — Maîtrise des collections Python et structures de données complexes.

### 🏗️ Architecture & Système (04 - 07)
- **Module 04 : System Mastery** — (Contenu du module 04 basé sur la suite logique).
- **Module 05 : Code Nexus** — Polymorphisme et flux de données adaptatifs dans la matrice.
- **Module 06 : The Codex** — Mystères des imports, packages et résolution de dépendances circulaires.
- **Module 07 : DataDeck** — Architecture abstraite et interfaces via un moteur de jeu de cartes.

### 🌌 Concepts Avancés (08 - 10)
- **Module 08 : The Matrix** — Environnements virtuels, gestion de packages et pipelines réels.
- **Module 09 : Cosmic Data** — Validation stricte avec Pydantic et modèles de données spatiaux.
- **Module 10 : FuncMage** — Programmation fonctionnelle, décorateurs et magie des fonctions d'ordre supérieur.
